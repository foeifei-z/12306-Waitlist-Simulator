# 模拟12306车票候补模块（基础版） - C语言实现

## 📌 项目简介
本项目是基于 C 语言实现的“模拟12306车票候补模块”。当旅客未买到票时，可以提交候补订单。系统严格按照“先来后到”的排队原则，当有退票或放票产生余票时，从队头开始依次为候补用户分配车票。本项目采用单链表实现队列结构，实现了完整的内存管理和良好的交互体验。

## 🛠️ 功能特性
1. **新增候补订单（入队）**：录入订单号、旅客姓名、身份证号，将订单追加至队列尾部。
2. **余票发放**：输入本次释放的余票数量 `k`，系统按提交时间先后顺序分配车票，分配成功的订单出队并输出信息，直到余票耗尽。
3. **队列状态查看**：实时查看当前候补队列中所有订单的排队顺序。
4. **退出程序**：安全退出并释放所有动态分配的内存，防止内存泄漏。

## 💻 设计思路
* **数据结构**：选用**单链表**实现队列，入队和出队时间复杂度均为 O(1)，避免数组队列的“假溢出”问题。
* **核心逻辑**：使用 `while(k > 0 && !isEmpty(q))` 循环持续从队头取出订单分配，直到余票耗尽或队列清空。
* **内存管理**：入队 `malloc` 申请，出队 `free` 释放，程序退出时遍历释放剩余节点。
